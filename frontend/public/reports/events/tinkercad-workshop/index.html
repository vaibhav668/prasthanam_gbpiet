Workshop Overview

Tinkercad Workshop was an interactive, hands-on learning session where participants learned to design, simulate, and build basic electronic and 3D projects using Tinkercad, Autodesk's beginner-friendly online simulation platform.

The workshop introduced students to the essential concepts of 3D modeling, circuit design, Arduino microcontroller programming, and virtual circuit simulation. Attendees had the opportunity to experiment, build, and debug innovative electronics and robotics projects virtually without requiring immediate physical hardware components.

Workshop Objectives

  1. Understand the fundamentals and UI of Tinkercad.
  2. Design simple 3D models using basic geometric shapes.
  3. Create and simulate electronic circuits with components like LEDs, resistors, and sensors.
  4. Program an Arduino microcontroller using basic C++ and block code.
  5. Develop a small functional project prototype.

What Participants Learned

  • 3D Design: Create and modify 3D objects using basic geometric shapes and alignment tools.
  • Circuit Design: Build virtual circuits using components including LEDs, resistors, switches, sensors, and potentiometers.
  • Arduino Programming: Learn basic Arduino programming and control electronic components and displays (like LCDs).
  • Simulation: Test and troubleshoot circuits virtually before constructing them physically.
  • Prototyping: Turn ideas into working prototypes quickly without physical hardware constraints.

The Tinkercad Circuit Designing & Simulation Event

Following the instructional workshop, students participated in the Circuit Designing & Simulation competition to apply their learnings in real-time under timed conditions.
